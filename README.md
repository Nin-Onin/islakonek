# IslaKonek: Contact Management System

## 📖 About
IslaKonek was developed as an individual project for On-The-Job Training/Internship to enable the student to learn and utilize Laravel, a robust back-end framework for PHP. It is a straightforward yet powerful contact management system meticulously crafted using the PHP Laravel framework, along with Tailwind CSS and MySQL as the database. The main objective was to implement CRUD operations to establish a basic foundation for interacting with the database.

## ⚙️ Getting Started
### Prerequisites
* PHP 8.x <br>
* Composer <br>
* MySQL <br>
* Node.js & npm <br>
### Installation & Run
1. Clone the repository <br>
   &nbsp;&nbsp; `git clone https://github.com/Nin-Onin/islakonek.git` <br>
   &nbsp;&nbsp; `cd islakonek`
2. Install PHP dependencies <br>
   &nbsp;&nbsp; `composer install`
3. Install Node dependencies <br>
   &nbsp;&nbsp; `npm install`
4. Copy the environment file and configure your database <br>
   &nbsp;&nbsp; `cp .env.example .env`
5. Configure your database credentials in the `.env` file <br>
   &nbsp;&nbsp; `DB_DATABASE=your_database_name` <br>
   &nbsp;&nbsp; `DB_USERNAME=your_username` <br>
   &nbsp;&nbsp; `DB_PASSWORD=your_password`
6. Generate application key <br>
   &nbsp;&nbsp; `php artisan key:generate`
7. Run database migrations <br>
   &nbsp;&nbsp; `php artisan migrate`
8. Build Tailwind CSS assets <br>
   &nbsp;&nbsp; `npm run dev`
9. Run the application <br>
   &nbsp;&nbsp; `php artisan serve`
10. Open your browser and go to <br>
    &nbsp;&nbsp; `http://127.0.0.1:8000`
